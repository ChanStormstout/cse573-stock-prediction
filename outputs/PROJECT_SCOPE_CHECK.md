## 2. 我们自行选择的实现

预测 AAPL / AMZN 在未来完整一小时的非平盘涨跌；使用截止前的价格和新闻。小时周期、提前 5 分钟截止、4 小时新闻窗口、6 个历史小时、训练/验证/测试月份、平衡准确率等均是我们的设计，不能说成老师指定。

已实现数据审计、时间安全样本、传统 LR/词特征参照、冻结 FinBERT 特征、按时间评价及案例诊断。这些直接服务主任务。冻结 FinBERT 是现代预训练特征的使用，不是本组训练了完整深度股票预测网络。

## 4. 范围纠正与收敛

此前改进计划使用“主线必做”等措辞，表示助手提出的实验优先级，不是老师规定。需要纠正这个容易造成误解的表达。为追求 performance 增加多条探索，使最近工作偏重新闻处理与模型抽取诊断；与交付物相比，投入比例需要收敛。

接下来优先完成：

1. 整理已跑实验与失败原因，保留有效对照、质量局限和复现记录。
2. 明确传统基线、一个现代特征方案和少量关键改进，固定最终比较范围。
3. 做能展示“历史价格与新闻输入 → 涨跌概率 → 对照与实例”的离线原型，清楚标出历史数据范围。
4. 对齐提案、分工、展示和最终报告；方法冻结后统一评估留出的最终测试。

暂停扩大结构化 LLM、注意力、GRU 等额外探索。课程资料没有规定必须复现全部论文，也未给出必须达到的准确率门槛。高分不能保证；应优先确保要求覆盖、实现正确、实验解释清楚和交付完整。
