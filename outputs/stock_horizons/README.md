# 预测周期对照：1h / 4h / day

## 目的与证据边界

检验预测周期是否比继续增加模型复杂度更值得调整。所有数据时期已经参与旧实验和方案设计；本轮是探索性历史回测，不能恢复独立测试资格。完整协议在开始训练前保存于 `runs/v1/protocol.json`。

## 定义

- 1h：原每个完整常规交易小时；与旧版本样本、标签、16个价格特征、新闻标题输入逐一核对。
- 4h：从每个整小时起点开始，连续四个盘中小时，不跨夜。相邻目标可能重叠三小时。
- day：常规交易日开盘至收盘，短交易日按实际收盘；不包含隔夜收益。
- 三者均在目标开始前五分钟预测，使用最近六个已经完整结束的小时价格特征及过去四小时新闻。
- 新闻沿用原语言、正文长度、时间、标题公司命中、去重规则。文本使用标题 TF-IDF，至多100维，L2 LR；本轮不代表全文、语义编码或所有新闻窗口已被排除。
- 独立按目标删除平盘，缺少任何必要五分钟线即排除。缺失、平盘、历史不足分别留在 coverage.csv。原分类实验不修改。

## 三个匹配模型

价格 LR；价格＋新闻数量/有无新闻；价格＋相同数量字段＋标题文本。C仅 .01/.1/1，所有缩放与词表在训练折拟合。使用六月、七月、八月向前验证均值BA选参，平手看Brier和较小C。随后冻结一至八月模型，分别报告九十月、十一月以后以及各月结果。

这里的C搜索是完整学习流程的公平预算，并非固定平均损失正则化的样本量因果实验。不同周期的数据量不同，不把差异全归因于预测距离。

## 两种观察面板

1. 全部各自合格窗口：贴近实际不同预测任务，保留覆盖差异。
2. 两股、三个周期共同合格开盘日期：同一时点信息，目标标签不同。此面板使用原全窗口训练的冻结模型，只是评估子集，不是开盘专用重训。

按交易日进行配对bootstrap，提供单日和五日连续块的新闻相对价格增量区间。区间为描述性，未校正多轮探索。四小时重叠样本不作为独立重采样单位。不同周期本来不是相同任务，不直接将跨周期差值命名为算法提升。

## 复现

从项目根目录执行：

```
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 work/stock-data/finbert-env/bin/python outputs/stock_horizons/run.py
```

默认拒绝覆盖 runs/v1，包括失败目录。输入哈希、协议、样本、全部候选成绩、18个模型、模型训练键与预测键、逐窗口概率均保存。旧 E00–M09 文件不修改。

## 解释限制

日频开盘前四小时可能缺少新闻。这是冻结输入条件的周期对照，不是日频最佳系统。若后续尝试24/72小时回看，需另立输入窗口实验，并保留当前结果。日频样本较少；末尾不完整月份仍展示但不用于声称稳定优势。没有新增未暴露数据，因此不会自动宣布新的最佳周期已得到独立验证。
