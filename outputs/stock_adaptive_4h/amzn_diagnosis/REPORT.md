# AMZN为什么没有稳定提升：机制核对、案例和近期论文

2026-09-16。**结论：不是所有机制都已尝试；Amazon并非一直低于50%；当前缺口同时存在于候选选择、概率质量、输入语义和跨时期稳定性。** 本轮没有重新训练，也没有更改四小时标签或最终选定系统。完成了保存结果重算、24个案例阅读、24个模型贡献重现、一个漏列对照补齐和近两年论文核查。

## 一、哪些真的试过

四小时价格/标题/正文/冻结FinBERT、完整静态组合、新闻增量、受约束条件选择、校准和成熟标签在线更新均已实际执行。最新两版共464次主拟合；其中没有FinBERT微调。更早的容量/学习曲线、月度更新分解、GRU、LoRA和PPO确实训练过，主要是一小时任务，不能说都已在四小时复现。

事件抽取修复、覆盖审计、证据关系存储已实现，但独立复核未通过，新增正文候选和正式关系输入尚未进入预测。新注意力、可学习投影＋LoRA、GNN、完整StockNet/CausalStock、SPY/QQQ分钟市场输入及连续四小时收益辅助目标未训练。详见[逐项状态](MECHANISM_STATUS.md)。

另发现N00承诺的“按过去OOF选择旧单分支”此前漏列。本轮先登记[补充协议](ADDENDUM.md)，再用保存的3—8月预测选择，补齐该行，未事后选后续赢家。结果AAPL选择正文、AMZN选择价格，后续BA51.74%/46.20%。原选定系统仍是标题baseline。

## 二、先纠正“Amazon一直没有超过50%”

相同后续179个四小时窗口、60个交易日，2018-11至2019-02初；全部已暴露，属于探索性历史回放。

| 方法 | AMZN BA | Brier，越低越好 |
|---|---:|---:|
| 恒定输出50%概率 | 50.00% | 0.2500 |
| 价格＋标题baseline（当前最终选定系统） | 48.92% | 0.2772 |
| 价格LR | 46.20% | 0.2677 |
| 旧价格＋全文 | **53.20%** | 0.2608 |
| 旧价格＋FinBERT | **52.22%** | 0.2711 |
| 旧完整组合 | 48.67% | 0.2610 |
| 最新零截距条件组合候选 | 46.20% | 0.2677 |

BA是上涨和下跌识别率的平均。恒定预测某一类在两类都存在时BA为50%；随机猜测的单次有限样本成绩会波动。53.20%不是“已经证明稳定优于随机”的结论。四小时窗口还彼此重叠，179行不是179次独立事件。

旧全文逐月BA：11月44.44%、12月58.95%、1月52.21%，2月仅2行不作稳定性判断。其概率误差仍差于恒定0.5，说明方向小幅占优与概率可信是两个问题。

## 三、case study先怎样设计，再怎样执行

先保存[PROTOCOL.md](PROTOCOL.md)，再选择案例。总体先重算AMZN全部305行：开发126、后续179。三组匹配比较为全文/标题、全文/旧组合、标题/新gate；每组分开发/后续，再各取“都对、都错、前者对、后者对”。使用固定哈希排序、优先不同日期，不按故事挑选。

最终24行来自24个不同日期，13个有新闻、11个无新闻；读取全部所选窗口标题和20篇正文节选（每篇至多5500字符）。先隐藏预测及收益写下内容笔记并封存，再揭示结果。之前已有项目经验，因此不是独立盲审，也不是全数据人工验收。此面板按对错分层，不能据此计算全体错误原因的占比。

随后重载旧全文模型，精确分解24例的价格、文本和截距贡献，概率重现误差小于1e-12。完整[案例解释](CASE_INTERPRETATIONS.md)、[阅读前后记录](analysis_v1/content_notes_before_reveal.json)均保留。

## 四、已核实的失败环节

### 1. 最新46.20%首先是“选了什么”的结果

AMZN训练期两个新闻分支的所有C候选均未通过Brier限制，最后C为空、修正归零。**全部305个冻结窗口的新gate与价格概率在浮点误差内一致（最大差1.11e-16），方向完全相同，包括有新闻的窗口。** 所以该结果不能解释成“复杂新闻模型训练后依然只会随机猜”，它实际没有采用新闻增量。

例如零截距正文C=0.01在训练向前月份平均BA57.53%，Brier0.25654；相同价格底座Brier0.25269。恶化0.00385超过预设0.002，故拒绝。这个门槛会舍弃可能有方向价值、但概率过度自信的候选。门槛有设计理由，不是程序错误，也不保证回退提高方向准确率。必须在训练期检验分支校准/收缩是否能改善取舍，而不是看后续分数后放宽门槛。

价格模型后续上涨召回60.64%，下跌召回31.76%，平均正好46.20%。它在64.25%的窗口预测上涨，而实际上涨52.51%；缺失下跌识别是具体表现，不能只说整体准确率低。

### 2. 旧组合确实损失部分全文预测，但全文自身不稳定

后续有新闻84行：全文BA55.43%，旧组合47.24%。逐行比较，全文对/组合错12次，组合对/全文错7次。

无新闻95行：全文对/组合错8次，反向5次。旧组合强制换回单独价格模型；全文联合训练的价格系数原本不同。

案例C11（2019-01-15）：无新闻，实际四小时上涨2.09%；全文概率52.87%正确，组合因回退价格45.04%错误。已确认文本贡献严格为零。**这次“全文赢”来自价格部分，不能归功于新闻理解。** C04则是无新闻时全文错误、价格正确，必须同时报告。

范围更正：之前日志在“有新闻”描述后写20对12，容易误读；20对12属于全部179行，有新闻子集才是12对7。本轮`paired_decomposition.csv`按类别分母精确核对BA差值；不平均各子集BA。

但提前选出全文并不容易：旧模型3—8月向前月均BA，AMZN价格54.16%、全文50.10%，全文Brier也更差。按过去选单分支仍会选价格；不能利用后来53.20%倒推过去一定应该知道。

### 3. 新闻字段缺少真正的对象、变化和时间关系

| 案例 | 实际读到的内容 | 说明什么 |
|---|---|---|
| C15，2018-10-26 | EPS5.75高于预期3.08；营收56.58低于57.11；未来指引66.5–72.5低于预期73.79（后两项单位十亿美元） | 增长/超预期/不及预期同时存在，需要指标、期间、预期配对；单一情绪不够 |
| C14，2018-10-08 | 政府支持苹果/Amazon否认芯片指控，正文同时复述原指控和之前跌幅 | 应区分新进展与历史背景；即使是正面更新，之后仍跌2.30%，语义修复不保证方向修复 |
| C12，2019-01-31 | 财报将于收盘后发布，但本窗口预测到收盘前结束 | 预告不是结果；长期或区间外信息未必预测这四小时 |
| C21，2018-09-19 | 9月5/6日市场下跌报道才被抓到，部分发布会预告也已过期 | 可用时间不等于新事件时间；这例模型还预测正确，缺陷与错误不能简单一一对应 |
| C03，2019-01-08 | Google销量追赶、Amazon存量优势与三年翻倍预测混合 | 竞争对象、存量/增量、三年/四小时均被词袋丢失 |

特别检查C15：全文确实比组合正确，但最大的词贡献包括direct、momentum、year等。这只能证明线性词关联影响了预测，不能写成“模型正确理解了营收不及预期”。C03中的其他公司词也产生实际贡献，说明杂讯不只是肉眼觉得无关。

### 4. 缺新闻是真限制，但不是唯一原因

后续95/179窗口没有入选新闻，正文候选审计虽可把潜在覆盖84提高到99，尚未验收和训练。另一方面，有新闻时价格/标题也可能很差，且有新闻本身不是随机分组；不能因覆盖低就断言这是唯一原因。24例中保留无新闻共同错误，防止把全部失误都讲成新闻故事。

**综合判断：现有表示学到的关系跨时期不稳定；组合和回退有时丢掉已有正确判断；候选选择又会因概率质量关闭新闻；有限且不完整的语料缺少事件进展、对象和预期差。各因素贡献未被全部因果量化。** 当前证据不足以断言不存在可预测信号，也不足以保证换大模型必定有效。

## 五、近期论文和下一步

详见[近期论文核查](RECENT_PAPERS.md)：GS-Fuse（KDD2026）、StockMem（2025预印本）、RETuning（2025预印本）、CAMEF（KDD2025）、FactorGCL（AAAI2025），以及一项2026情绪迁移研究。最值得借鉴的是“事件新增信息/预期差”和“基于真实增量预测价值的内容门控”。它们的数据、任务、评价并不等同于我们的四小时BA。

建议顺序，以下**尚未新训练**：

1. **先单独验证分支概率校准＋有限收缩。** 使用过去前向OOF，在更早前缀拟合校准并预测后续折；正文/语义各自处理，再比较固定0/.25/.5/.75/1修正幅度。保留全关、原始分支、当前选择器和标题baseline。冻结规则后回放，控制候选数量，不能用后续结果调阈值。
2. **小范围验证真正缺失的关系字段。** 指标—期间—实际/预期、当前公告—历史背景、指控—否认/取消、公司对象。覆盖原文不直接删除；不确定标记保留；组员独立检查不足时，只能做助手暂定探索。抽取准确与预测有效分开验收。
3. **分支出现一致增量后再让gate读内容。** 当前gate主要读取年龄/覆盖/分歧等，不能分辨“否认”和“指控”；借鉴GS-Fuse加低维内容，与原gate等预算比较，不一次更换全部模型。
4. **可靠新数据、市场因素再独立扩展。** 不能用两个股票的脆弱实体关系强行上完整GNN，也不继续盲目扩大LoRA/RL搜索。

这些是有证据指向的实验方向，不是收益承诺。历史时期已经参与设计，必须保留探索性声明；若获得新时期，先锁定再做最终检验。

## 文件与复现

- `analyze.py`：人口级统计、配对分解、确定性案例；默认拒绝覆盖analysis_v1。
- `content_notes.py`：结果揭示前笔记的生成记录，已封存，不重新改写。
- `addendum.py`：OOF单分支补充和保存模型贡献；成功目录addendum_v2。v1因历史pickle主模块类名无法解析中断，结果保留，v2仅修复类名绑定。
- `write_deliverables.py`：核验原始哈希/笔记封存，生成案例解释、状态与Sources收据；无模型拟合。
- 重算需要把输出目录改为新目录；使用原`work/stock-data/finbert-env/bin/python`，不覆盖历史模型、实验结果或封存笔记。
