# N00--N05 four-hour execution protocol

Registered before new training. Parent design: `../stock_integrated_4h/next_plan/PLAN.md`.
All old runs immutable. 1607 four-hour rows, unchanged labels, t-5min cutoff, same articles. All periods are exposed exploratory history.

Core: original price/title LR with C=.01/.1/1; C selection starts with March ledger to reproduce original final baselines. February price OOF (fixed .1) is additional warmup supervision, not an extra score used by the legacy C selector. Residual training requires 60 earlier price OOF rows/20 dates/both classes. Therefore first residual fits occur in April, because February supplies only57 rows per stock. Body100 terms, frozen title FinBERT/PCA16 on unique residual-training articles. Offset sum-log-loss plus L2 coefficient penalty, gated news intercept unpenalized. Joint diagnostic additionally unlocks price coefficients and an unpenalized intercept. Raw convex training; corrections clipped to[-1,1] for every selection/evaluation prediction.

No-event probabilities are copied exactly for all residual/mixture models (joint diagnostic deliberately permits price changes). 15 static simplex candidates. Router: pooled Ridge on complete-chain chronological OOF losses relative to price;8 documented context variables plus penalized stock indicator. Alpha1/10/100, rho0/.25/.5; softmax temperature.05. Minimum200 complete OOF rows,60 common dates, each stock30 news rows/20 news dates. Outlier>=3 context dimensions outside fitted1--99percentiles -> static fallback. No mature history -> static fallback. Future-label updates prohibited. Guardrail for residual C and static/gate selection: matched Brier+.002; then mean monthly BA, Brier, stronger regularization/smaller dynamic weight. No eligible residual C -> zero correction. These defaults/limits are not claimed optimal.

Shared calibration uses base OOF only, bounded monotone(a,b), identity-centered fixed penalty. Report price/static/gate with and without it. Warmup identity. All fits, transforms, OOF keys and temporal dependencies saved. Meta fit and selected predictions remain chronological at every layer. June--August complete predictions provide budget screening; selected candidate must improve two-stock macro BA by >=1pp, win >=2/3months, neither stock lose>1pp, Brier guardrail each stock. Else selected system is the unchanged title baseline. This is a development decision, not independent evidence.

Frozen September onward: no outcome adaptation; dynamic context only. Online N05 separate: fixed experts,20completed-day Brier estimates shrunk by20training pseudo-days,weights half recent softmax/half frozen static. Price/title adaptive intercept controls receive identical mature outcomes. Same-day outcomes unavailable until next trading day. No test tuning.

N04 audits raw coverage and repairs evidence extraction independently of forecast outcomes. No new article/relationship may enter prediction until independent review gates pass. Existing40-case human review remains pending. Rule-derived direct/mention labels are provisional, never gold. Same input articles/decoder/token budget mandatory for conditional future input comparisons.

Core files and protocol frozen by hash in each run. Code bug repairs require a new run or an explicitly recorded post-training reporting revision, with old outputs preserved. No parameter revision after viewing later scores.
