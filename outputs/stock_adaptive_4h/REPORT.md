# 四小时完整流水线：实施与实验结论

## 结论

**代码、真实训练、完整推断和对照已完成；两版新系统均未得到同时改善 AAPL 与 AMZN 的证据。预设选择规则保留标题 baseline。** 这不代表之前的四小时结果被推翻，也不代表市场没有可预测信息。

本轮沿用 1,607 个四小时窗口；输入截止在目标起点前五分钟，目标使用同日 48 根完整五分钟线。2018 年 1—8 月用于分层前向训练与选择，9—10 月为开发回放，11 月至 2019 年 2 月初为已暴露的后续历史回放。所有这些时期都已参与项目探索，不能称为新的独立测试。

## 1. 实际实现了什么

| 阶段 | 本轮实现与执行状态 |
|---|---|
| N00 数据合同与 baseline | 验证原输入、缓存、截止时间；重新训练价格及价格＋标题 TF-IDF＋L2 LR，最终 baseline 概率与旧运行一致 |
| N01 新闻增量 | 价格底座只保留一次；正文 100 词、冻结 FinBERT/PCA16 分别学习对价格 logit 的修正；比较允许价格系数重新变化的联合对照 |
| N02 有约束选择器 | 静态组合包含零修正；小型 Ridge 预测两新闻分支相对价格的损失，权重向静态组合收缩；样本不足、异常上下文和无新闻均明确回退 |
| N03 校准 | 同一价格 OOF 拟合单调概率校准，分别报告校准前后，避免把校准收益算成新闻或 gate 收益 |
| N04 覆盖与关系 | 扫描原始候选、修复对象与动作抽取、保存证据位置和未知项；独立复核未完成，因此新文章和关系没有进入预测 |
| N05 在线更新 | 仅用前面已完成交易日的误差有限更新权重；同时跑获得相同成熟标签的价格/标题截距更新对照 |
| N06 高级模型 | 继续条件未通过，未进入新的注意力、LoRA 或 Graph 训练 |

每层监督来自当时能够获得的前向样本外预测：价格先预测后续月份，新闻修正器再学习更早月份的价格误差，选择器只能学习更早月份完整分支的误差。没有把训练内高分交给下一层当作泛化能力。

主协议见 [PROTOCOL.md](PROTOCOL.md)。发现偏差问题后只增加一个针对性版本：[ZERO_BIAS_PROTOCOL.md](ZERO_BIAS_PROTOCOL.md)，将新闻修正截距固定为零，重新跑完整训练和选参。两个版本后停止扩网格。

## 2. 同一后续时期的完整对比

BA 是上涨与下跌识别率的平均；越高越好。Brier 衡量概率误差，越低越好。这里 AAPL 有 178 个窗口，AMZN 有 179 个窗口。

|---|---:|---:|---:|---:|
| **主 baseline：价格＋标题 TF-IDF＋L2 LR** | **51.89%** | **0.2694** | **48.92%** | **0.2772** |
| 价格 LR | 51.79% | 0.2720 | 46.20% | 0.2677 |
| 旧四小时完整组合 | 55.69% | 0.2630 | 48.67% | 0.2610 |
| 旧价格＋全文 | 51.74% | 0.2587 | 53.20% | 0.2608 |
| 旧价格＋FinBERT | 56.71% | 0.2856 | 52.22% | 0.2711 |
| 第一版：正文修正 | 51.57% | 0.3076 | 46.20% | 0.2677 |
| 第一版：语义修正／静态组合 | 52.62% | 0.3080 | 46.20% | 0.2677 |
| 第一版：条件组合 | 51.52% | 0.3041 | 46.20% | 0.2677 |
| 第一版：条件组合＋校准 | 50.45% | 0.3014 | 46.90% | 0.2641 |
| 零新闻截距版：正文修正 | 54.09% | 0.2801 | 46.20% | 0.2677 |
| 零新闻截距版：静态／条件组合 | 51.79% | 0.2720 | 46.20% | 0.2677 |
| 零新闻截距版：条件组合＋校准 | 52.97% | 0.2712 | 46.90% | 0.2641 |
| **按预设继续条件选择的系统（两版均如此）** | **51.89%** | **0.2694** | **48.92%** | **0.2772** |

旧方法用于历史参照；正文维度、训练形式和选择链不同，不能把新旧差值全部归因于单个组件。正文锁定/解锁价格的 J 对照、所有月份、MCC、类别召回与预测上涨比例，均在两份完整结果表中保留：

- [第一版全部结果](results/v1/REPORT.md) / [指标](results/v1/metrics.csv)
- [零新闻截距版全部结果](results/zero_bias_v2/REPORT.md) / [指标](results/zero_bias_v2/metrics.csv)

**不能根据后续分数，事后指定苹果用新正文、亚马逊用旧全文，然后称为经过验证的选择器。** AAPL 正文 54.09% 是诊断发现，未通过完整系统的训练期选择。第一版 gate 相对静态组合在 AAPL 后续期修正 0 个、增加 2 个错误；不能宣称条件选择有益。

## 3. 为什么新设计仍没有成功

### 3.1 新闻修正器把过去的方向偏差当成了“新闻贡献”

AAPL 训练期 440 个价格 OOF 样本：平均上涨概率 49.91%，实际上涨比例 58.64%。后续时期：价格平均上涨概率 58.66%，实际上涨比例仅 48.88%。过去需要的整体向上修正，在后续时期并不适用。

第一版正文修正的截距是 +0.594，语义修正截距是 +0.417。后续正文修正 100% 为正，语义修正约 98.31% 为正。这证明该模型存在几乎一律上调的行为，不能把它解释为逐篇新闻提供了可靠利好信息。它是有证据的失败机制之一，不是对全部失误的因果解释。

因此第二版把新闻截距固定为零，保持其余输入、候选、时间账本和选择规则不变。AAPL 正文 BA 从 51.57% 到 54.09%，Brier 从 0.3076 到 0.2801，说明减少这种偏差有帮助；但概率误差仍高于标题 baseline 的 0.2694，AMZN 没有改善。这个结果不足以把该方案升格为稳定改进。

### 3.2 选择器无法创造分支尚未学到的能力

AMZN 的新闻修正候选在早期月份未通过预先设置的 Brier 限制，最终修正为零。于是即使某窗口有新闻，条件权重也不能产生有用修正。零截距版最后选择 rho=0，退回静态组合；静态组合本身选择零新闻修正。

这说明保护规则正在工作，但**保护规则有效不等于模型表现更好**。价格回退与标题 baseline 的价格系数也不同；已有案例显示，回退价格会丢掉标题模型原本正确的预测。不能把“更保守”写成“必定更准确”。

### 3.3 输入语义和时间问题尚未被架构修好

实际审阅的案例仍包含：过去季度持仓变化、分析师历史列表、其他公司的新闻、指控与否认并存、相同事件近似转载，以及长期利好但四小时下跌。同一个 Canaccord 上调苹果目标价事件，在相邻小时起点可以对应相反的四小时标签。

正文词袋和冻结标题语义向量并没有完整理解这些关系。选择器输入只有覆盖、年龄、波动和分支分歧等少量信息，也不能辨别“指控是否被否认”。因此本轮解决的是重复计算价格、监督时间和选择器过拟合风险，并未凭空解决新闻事实理解。

见 [CASE_REVIEW.md](CASE_REVIEW.md)：64 个确定性案例卡中实际审阅 16 个窗口、23 篇文章节选；生成案例不冒充全部人工审阅。

## 4. AMZN 缺新闻：过滤确实漏掉了一部分，但还不能宣布补齐

扫描 78,055 条原始索引；59,813 条通过语言、正文、基本时间等可用性条件；读取在原窗口中可用的 14,105 条正文。标题以外确实有 Amazon 直接信息，例如 Telsey 首次给予 Outperform、Credit Suisse 目标价 1750→1800。

初版覆盖规则过宽，把市值比较、泛泛意见和另一家公司评级也当作直接事件。审阅后收紧规则，并保留旧结果与代码快照。最终候选统计：

| AMZN 时期 | 原有新闻窗口 | 加入规则候选后的潜在窗口 | 新候选文章 |
|---|---:|---:|---:|
| 训练 | 258 / 499 | 286 / 499 | 35 |
| 开发 | 73 / 126 | 73 / 126 | 2 |
| 后续 | 84 / 179 | 99 / 179 | 21 |

这些是**尚未独立验收的潜在数量**。候选中仍有历史事件和背景，严格规则也可能漏掉招聘等事实。任何新增文章尚未进入本轮预测，因此没有将候选数量增加写成预测收益。

抽取现已分别记录评级动作、目标价动作、新旧值、单位/期间、目标公司、证据字符位置、发布时间/可用时间、冲突和未知项。机构不可靠时为空，不猜首次披露日期。已有错误有回归测试。

- [覆盖与案例说明](COVERAGE_REVIEW.md)
- [65 行独立检查表](coverage/v3/independent_check.csv)：已复核 0 行；每拟使用类型要求至少 30 个非重复事件组、关键字段正确率至少 90%；覆盖和漏抽另报。
- 原来的 [40 篇正文独立检查](../stock_four_hour_v2/review/blind_review_40.csv) 仍未完成，不能用新表冒充已补完。

助手检查只用于开发和探索。完整关系输入及 Graph 分支保持未验收；这是按用户既定质量条件保留的分支状态，不阻塞已完成的训练与交付。

## 5. 在线适应与不确定性

使用前 20 个完整交易日误差、再向训练期先验收缩的权重更新也已执行。第一版 AAPL 后续 BA 为 50.95%；零截距版为 53.49%；两版 AMZN 均为 46.20%。同信息的价格截距更新是 51.77% / 44.13%，标题截距更新是 51.87% / 47.91%。不能只拿在线模型与完全冻结的模型比较，然后把差异全部归给算法。

零截距版在线权重相对标题 baseline 的 AAPL BA 差 +1.60 个百分点，五交易日块描述区间约 [−1.35, +4.39]；AMZN 差 −2.72，区间约 [−6.68, +0.97]。这些区间来自 10,000 次共同交易日配对重采样，同时保存单日/十日块敏感性；没有校正反复探索，不能当作新发现的显著性证明。2019 年 2 月只有两行，单独显示，不作稳定性论据。

## 6. 真正训练与核验的证据

两个有效主运行分别完成 **233 / 231 次实际拟合**，总计 464 次（价格/标题、新闻修正、校准与 Ridge 选择器）。保存全部权重、OOF、选参明细、数据和代码哈希。在线每版另有 408 次小截距拟合，另 408 次仅用于未来标签扰动验证，不能算作新增模型搜索。

FinBERT 编码器使用已核验的冻结文章缓存；本轮训练的是下游模型和训练期 PCA，并未微调 FinBERT。核心 CPU 训练约 9 / 6 秒，缓存准备、原文扫描、核验和报告不包含在该时间内。样本少、维度小，所以无须 Sol。

FinBERT 是事后可获得的历史表示工具。本轮时间检查针对监督标签和特征可用性，不认证预训练语料与该历史时期完全无重叠，也不把回放当成当年真实可部署的策略。

- [第一版核验](runs/v3/verification.json) / [第二版核验](runs/zero_bias_v1/verification.json)：独立重算 1,607 个原始四小时标签；各 609 个冻结样本去掉标签后重新推断，概率最大误差 0；选参/权重重算、未来标签扰动、哈希及无新闻严格回退通过。
- [27 项回归与边界测试](tests.txt) 通过，覆盖时间拒绝、缓存失配、选择器支持度/异常输入、修正不改写上游概率、证据与恢复检查等。
- [浏览器演示检查](DEMO_QA.md) 完成。该演示调用实际保存模型，未来真实收益仅在另选“显示实际结果”后展示。

工程修复记录：最初 v1 因新代码共享内存导致上游概率被修改而中断，已经修复并加入测试；v2 预测完成但 NumPy 元数据类型写为字符串，v3 修复序列化后重跑且预测与 v2 一致。覆盖 v1 的混合时间解析、覆盖 v2 的过宽规则、第二版报告的路径错误及 demo 引用旧同名模块均已修复；保留失败/旧记录，未覆盖历史实验。没有使用失败 v1 得分。

## 7. 现在完成和未完成的边界

已完成：真正可训练、可预测、可复核的完整四小时系统；两版有限对照；逐月/分股/概率指标；案例与覆盖调查；运行说明和本地 demo。

未达到：两股稳定方向增益、事件独立质量验收、合格的新时期确认。免费数据调查没有建立可可靠对齐的新增四小时数据分支，详见 [FREE_DATA_FEASIBILITY.md](FREE_DATA_FEASIBILITY.md)，不据此断言免费数据不存在。

下一项有明确价值的前置工作是独立复核和可靠数据覆盖，而不是继续放大同一选择器网格。若复核通过，再依原方案对相同候选文章做原文本/关系表示的匹配比较；届时必须重新报告覆盖变化、预测收益和不确定性。本轮没有为未通过条件的 Graph 或更深网络制造成绩。

运行入口与离线复现见 [README.md](README.md)，全过程已追加到 [PROJECT_LOG.md](../PROJECT_LOG.md)。
