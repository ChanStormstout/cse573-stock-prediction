# 四小时完整组合流水线与传统新闻 baseline

## 这次实际完成了什么
四分支训练 → 过去样本外预测 → 过去数据选融合权重 → 冻结完整系统 → 开发/后续历史回放 → 消融/案例/区间。完成 152 次成功LR训练，运行 22.2 秒。未使用一小时实验的权重或标签。

任务保持原四小时、1607窗口不变；每股训练499/499，开发126/126，后续178/179。完整系统并非把历次最高分拼接：它在每个截止点重新选择分支参数和组合权重。全部时段已参与过研究设计，本轮为探索性历史回放。

## 系统结构
- 价格：原16价格特征＋L2 LR。
- 标题 baseline：相同价格＋标题TF-IDF500＋L2 LR。
- 全文：相同价格＋既有清洗词干全文二值词袋、训练内卡方500＋L2 LR。
- 现代方法：相同价格＋冻结FinBERT文章向量、唯一训练文章PCA16、新闻数量/可用性＋L2 LR。
- 融合：四个概率非负加权；0/.25/.5/.75/1权重，共35个单纯形候选。无新闻严格回退价格。
- 选择：各分支C=.01/.1/1，按过去月份BA/Brier选择；融合使用严格前向分支OOF，Brier不比标题baseline恶化>.002的候选中选月均BA最高。没有合格项则保留原标题模型，不强迫新模型。

这里“机制协调”的含义是互补预测的保守融合、过去数据选择、无新闻回退、模型容量控制与端到端验证。未叠加没有收益的价格新特征、GRU、LoRA；独立复核未通过的目标正文抽取也未接入。全文是既有一般清洗正文，不冒充独立验收的事件抽取。

## 本轮结论与解释

本轮主目标严格为四小时：48根完整五分钟线从目标起点开盘到四小时末收盘的方向；信息截止为起点前5分钟。原1607窗口全部保留。

AAPL：BA 51.89%→55.69%（+3.80个百分点）；Brier 0.2694→0.2630。

AMZN：BA 48.92%→48.67%（-0.25个百分点）；Brier 0.2772→0.2610。

开发时期9–10月：AAPL baseline51.32%→组合53.52%；AMZN47.40%→51.21%。随后11月–2月，AAPL仍有增量，AMZN方向收益未保持。

冻结权重：AAPL25%价格+50%全文+25%FinBERT；AMZN25%价格+25%标题+50%全文。全部由三月至八月前向样本外预测选择，不使用后来结果替换权重。

后续期消融：AAPL去掉FinBERT后重新选权重，BA51.35%；去掉全文53.47%，均低于完整组合55.69%。这个结果支持组合在这一段AAPL历史上的增量；但相对baseline的5日块BA差区间约[-1.71,+8.72]个百分点，仍不足以确认稳定泛化。AMZN完整组合48.67%，去掉FinBERT不变（原权重为零），去掉全文46.20%。虽然全文分支有贡献，组合整体仍没有超过标题baseline。

AAPL单独FinBERT分支BA56.71%比组合55.69%更高，但其Brier0.2856比组合0.2630差；不能只取方向最高分代表概率质量全面提升。AMZN全文单分支53.20%优于组合，但不可事后用它替换训练期所选系统。

结论：四小时完整流水线已执行和核验；AAPL得到一个值得保留的组合结果，AMZN仍未得到稳定方向改进。此前一小时组合仅为辅助实验，不作为本项目主目标。所有时期已暴露，本轮属于探索性历史回测。
