# 独立盲查填写说明

`blind_review_40.csv` 按两股×2018年3至7月×每层4篇抽样，共40篇；不含未来收益或涨跌标签。保持sample_id、正文、提取片段不变。

请由组员逐篇对照 `body` 和 `extracted`，填写：

- `subject_correct`：1=提取内容确实关于该股票公司且没有把他家公司动作错归给它；0=对象错误、仅模板/顺带出现、或缺失到无法支持该表示。不要仅因字符串出现公司名就填1。
- `template_or_mixed`：正常 / 模板 / 多公司混合 / 不确定，并说明理由。
- `missed_target`：正文有相关内容但未抽取 / 没有漏抽 / 无相关正文 / 不确定。
- `reviewer`：实际独立复核人的姓名或组内代号，不使用助手代填。
- `review_note`：关键证据、遗漏、不确定点、近似转载/同一事件等。

抽取规则是按原文顺序保留至多两段明确含公司别名的正文，最终截断为254个内容token（加两个特殊token共256）。`source_spans`标记候选原段落的位置，可能长于截断后的输入；`extracted`才是实际模型拟用内容。某些正文缺乏换行，可能成为长混合段落，这正是待验收风险。

完成全部40篇后才计算对象正确率，至少90%是工程门槛，不是总体精度的统计保证；同时报告缺失、模板、多公司和漏抽情况，不删除失败案例。检查脚本每次都会重新验证，包括重启时。它只能核查填写和声明，不能独立认证复核人的身份。

当前尚未完成独立复核；未运行正文训练。`semantic_components.py`只包含校准、offset、PCA及闸门组件，完整文本实验编排仍待接入。
