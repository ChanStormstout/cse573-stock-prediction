# 监督、时间与模型互补性诊断

2026-09-15，已实际执行。只读取 E03/E04/E08 已保存的训练、开发验证数据与预测，没有训练新模型，没有读取最终测试数据或评价测试成绩。

## 新观察

| 项目 | AAPL | AMZN |
|---|---:|---:|
| 训练预测窗口 | 996 | 1,004 |
| 训练交易日 | 168 | 168 |
| 训练窗口内不同新闻记录 | 4,640 | 375 |
| 训练新闻覆盖率 | 99.30% | 56.67% |
| 在多个训练窗口出现的记录 | 3,767 | 306 |
| 其中同时对应过涨、跌窗口的记录 | 2,987 | 240 |
| 上一行占被重复使用记录的比例 | 79.29% | 78.43% |

新闻记录以 `archive::member` 区分，沿用 E03 修正后的版本识别。记录数不等于去重后的真实事件数，也不等于独立涨跌标签数。跨窗口出现不同标签是正常的时间依赖，**不能据此说原窗口标签有误或删掉这些新闻**。它直接说明：把每个窗口的标签复制给窗口内的每篇文章，会把不同时间与价格背景压掉；文章级微调不是合适的默认监督设计。

两股共享相同的 168 个训练交易日；验证为同样的 42 个交易日、每股 252 个窗口。跨日、跨股与窗口重叠带来的依赖未被简化成某个“有效样本数”，本轮不估计该数字。

## 两种相关性不能混用

| 描述性 Pearson 相关 | 训练 | 开发验证 |
|---|---:|---:|
| AAPL / AMZN 同一目标小时的收益 | 0.5698 | 0.7346 |
| 已知的 AMZN 过去收益 / AAPL 未来目标收益 | 0.0407 | −0.0024 |
| 已知的 AAPL 过去收益 / AMZN 未来目标收益 | 0.0544 | −0.0065 |

第一行的两种收益都发生在预测截止之后，不能把其中一股的同期真实收益放进另一股的预测。后两行使用截止前最后一根已结束的原数据中合格小时，信息年龄中位数 55 分钟，包含跨夜和周末；**没有检验全部 5 分钟滞后、非线性或条件关系**。弱的简单滞后相关不能证明图模型无用，强的同期相关也不能证明提前预测可行。以上不是因果检验或统计显著性结论。

## 时间稳定性

AMZN 9 月 → 10 月：

- 上涨比例 55.26% → 44.20%。
- 新闻覆盖率 76.32% → 58.70%。
- 目标绝对收益中位数 0.280% → 0.591%。
- 原 E08 序列 LR 的 BA 63.17% → 44.01%（引用既有结果，本轮未重训）。

这些变化说明两个开发月份的观测分布不同；不能单凭同步变化证明模型下降由某一项造成。AAPL 新闻均数也从每窗口 12.04 降至 6.49。完整各月数值在 `monthly_data.csv`，包括所有训练月份，不只挑选变化最大的月份。

## 模型能否互补

`prediction_overlap.csv` 按股票列出同协议的价格 LR、标题 FinBERT LR、稀疏词组合、序列 LR、GRU 种子 573 的所有两两错误对照。固定种子 573 用于诊断，不是选最优种子。

价格与标题 FinBERT 的错误指示变量相关性，两股都约 0.72。序列 LR 与 GRU 约 0.31，但 AAPL 的 GRU 相对序列 LR 改对 43 个、改错 44 个；AMZN 对应 44 与 43 个。更不相同不等于更有用，也不能证明概率平均一定无效。本轮**没有训练或评估融合模型**；若融合，权重必须从训练期向前折的样本外预测选取。

常数概率 0.5 的验证 Brier 为 0.25，提供直观概率基准。它不能自动推出最优方向阈值或说明哪个模型 BA 更好。原神经模型 Brier 大约 0.297–0.321，概率误差值得优先检查。

## 复现与边界

在项目根目录运行：

```sh
OPENBLAS_NUM_THREADS=2 OMP_NUM_THREADS=2 work/stock-data/finbert-env/bin/python outputs/stock_signal_audit/audit.py
```

输出 `audit.json`、`monthly_data.csv`、`prediction_overlap.csv`，并检查：仅有训练/验证行；标签方向一致；记录列表与数量一致；各预测一对一对齐；E04/E08 的相同基线预测一致；用于滞后诊断的其他股票收益在截止前已经结束。源文件及脚本哈希保存在 JSON。诊断基于原先的非平盘、历史完整的样本总体，不推广为全部市场时段。

这是一轮事后开发诊断。所有新设计详见 [原因分析与下一轮设计](../ROOT_CAUSE_AND_NEXT_DESIGN.md)；不能把新的诊断解释写成已证明的性能改进。
