## 1. 结论与证据边界

下一轮建议集中验证两个问题：**模型定期更新能否适应时间变化；目标公司的具体事件及信息时效能否比词袋提供更稳定的输入。** 这两项尚未完成。它们有明确的失败案例作为动机，不保证提升。

本轮核对了 E04、E05–E07、E09–E12 的协议、关键代码与报告。E12 的 AAPL 全文 L1/L2 测试 BA 为 49.24%/48.06%，AMZN 为 50.92%/55.04%，与用户提供的 side chat 一致。不能概括为所有方法在测试集失效；也不能把此前全部开发实验称为已经通过最终测试。

用户提供了另一轮只读审查，包括 3,233 个样本核对、`judg` 的分布、来源变化及迟到新闻案例。这些作为**用户提供的 side chat 诊断**记录；本轮未重新执行其全部逐样本、逐词统计。已保存的主实验结果与这些诊断在方向上相容，但尚无消融实验分离每项因素对分数下降的因果贡献。

原保留期 2018-11-01 至 2019-02-01 已在 E12 评估，现在又用于诊断。后续在该时期运行更新模型，属于受既有结果启发的历史回测。按时间重训可以防止未来标签进入过去模型，**不能消除整个方案已受这些结果影响的事实**。新的独立泛化确认需要另一个未用于设计的数据时期。

证据：[最终测试](stock_final_test/REPORT.md)、[本轮之前实验进展](EXPERIMENT_PROGRESS_20260915.md)、[持续项目日志](PROJECT_LOG.md)。

## 2. 哪些确实还没有尝试

| 方法 | 现有状态及区别 | 下一轮优先级 |
|---|---|---|
| 按月扩展训练、六个月滚动训练 | 未做；过去的扩展时间交叉验证是选参，最终预测模型仍冻结于 1–8 月 | 最高，先独立验证 |
| 动作对象、旧值/新值、披露证据组成的事件事实 | 未完成；E05 是选公司相关句，E07 是九类事件及失败的小模型 pilot | 最高，先验证抽取质量 |
| 按披露年龄保留绝对信息强度的聚合 | 未做；E04 是按可用时间的一小时半衰期、归一化情绪平均 | 随事件事实分步验证 |
| 浅层梯度提升树 | 当前代码未发现实现；此前非线性探索是 MLP/GRU | 次选；与 LR 使用相同少量数值特征 |
| 预测概率的后期融合 | 未做；价格和文本拼接、多个种子的指标平均不是概率融合 | 次选；用训练期样本外预测决定权重 |
| 学习每篇新闻的聚合权重 | 未做；FinBERT 内部 attention 和固定时间加权均不是文章重要性学习 | 条件候选，先与等权/固定权重比较 |
| 更灵活的 FinBERT 适配 | E10 已真实运行 LoRA；可学习投影、更多层及全文/可靠片段适配未做 | 后置，每次只改变一项 |
| StockNet 时间辅助目标、变分潜变量结构 | 未做；GRU、联合价格文本输入只是部分相关组件 | 后置，不要求完整复现 |
| 实体—事件—时间关系图及图学习 | 未做；两股部分共享 LR 已试，但不是 GNN | 事件事实合格后再决定 |
| 另一股票的历史收益直接作为输入 | 做过简单滞后相关诊断，没有等同于训练该输入的模型 | 可作廉价关系对照；不能用同时段未来收益 |
| 完整 CausalStock、完整 Twitter 突增系统 | 未做；前者结构化处理尚未合格，后者缺可核验历史流 | 不作为当前主线 |

SVM、朴素贝叶斯、随机森林等也未在当前实现中发现，但“再增加分类器名字”不是优先目标。小型提升树值得作为有限的非线性对照，不能预先声称它会优于 LR。[scikit-learn 集成方法说明](https://scikit-learn.org/stable/modules/ensemble.html)

StockNet 原方法确实包含连续潜变量、变分推断和时间辅助目标；我们的 GRU 实验没有实现这些完整机制。[StockNet 原论文](https://aclanthology.org/P18-1183/)

### 已经尝试，不再列为全新方法

最近完成的 5 分钟价格；过滤抓取延迟超过四小时的新闻；固定新闻时间衰减；目标公司相关句；近似转载归并；规则事件类别；冻结 FinBERT 情绪与语义向量；窗口级 LoRA；MLP/GRU 与训练期早停；独立/共享/部分共享 LR；全文 L1/L2；温度校准。

这些方法的具体实现没有稳定收益，不等于其全部可能设计都被否定。

## 3. 第一阶段：只改变模型更新方式

### 要区分的解释

- 扩展训练相对冻结：加入近期已实现标签并重新拟合，是否帮助适应变化？
- 滚动训练相对扩展：舍弃早期数据的潜在收益，是否超过样本变少的损失？

两种差值检验训练策略的整体效果，不能单独证明某个词语漂移是原因。

| 策略 | 预测 2018 年 12 月的例子 |
|---|---|
| 冻结 | 保留原 1–8 月模型 |
| 按月扩展 | 用 1–11 月已经实现的标签重训 |
| 滚动六个月 | 用 6–11 月已经实现的标签重训 |

建议从 9 月开始按月回放，两股共享日历边界，分别报告 9–10 月与原 11 月之后的保留期；2 月仅 1 日、每股 5 个窗口，单独列为小样本补充，不与完整月份等权解释。

### 控制与实施约束

1. 第一阶段保持原小时目标、全部样本、新闻集合和正文处理不变。不要同时换事件抽取器、新闻窗口或分类器。
2. 保留全文 L1/L2 两套匹配比较，形成每种正则下的三种更新策略；两股均完整报告，不根据已经看过的测试成绩拼接“苹果用 L1、亚马逊用 L2”的赢家系统。
3. 更新臂每次只从当时已实现的标签学习。词表、卡方筛选、缩放和参数选择全部限制在该次训练范围；不复用将来月份拟合的特征。
4. 延续小规模 C 候选和训练范围内的向前选参；冻结臂继续原协议，更新臂采用相同候选预算。每月重新选参/词表属于更新策略的一部分，不能把其整体收益只归因于系数更新。必要时再加固定原 C 的敏感性检查，第一阶段不同时扩网格。
5. 内层划分要模拟过去预测未来，按共同交易日期划分，并检查训练标签结束时间早于预测截止。不要把两股行数简单混在一起交给默认随机交叉验证。[时间验证与训练期预处理说明](https://scikit-learn.org/stable/modules/cross_validation.html)
6. 原 E12 模型、报告与哈希保留。新实验从准备数据开始使用独立目录，保存每月训练行键、来源指纹、所选 C、词表、模型与预测。

### 观察什么

除整体和逐月 BA/MCC/Brier，还记录样本数、上涨比例、新闻覆盖、选中词和系数的变化、高置信错误数。系数会随共现词和正则变化，单个系数变小不直接证明语义理解改善。

按共同交易日成对比较、做连续多日块的敏感性分析，避免将 729 个相关窗口当成独立样本。报告两股和失败月份，不以某个最好月份晋级。现有时期上的区间是描述性回测不确定性，不包含整个反复选方案过程。

## 4. 第二阶段：把“类别”提升为可核验的事件事实

先做分析师评级/目标价动作和公司业绩指引。目标是保存“谁对哪家公司做了什么改变”，而不是给整篇文章贴一个正负标签。

建议字段包括：目标公司、发起方、事件类别、评级动作、目标价动作、旧值、新值、单位/币种、指引指标、对应会计期间、当前披露/历史背景/未知、原文证据位置。字段不适用和抽取失败分别表示，不把缺失数值填成零变化。

特别注意：

- 目标价的旧值/新值只有对象、事件和单位匹配才计算变化比例。
- 业绩指引应区分收入/EPS、单季度/全年以及上下限；不能将不同指标硬算成一个百分比。
- “较去年增长”不是“上调指引”；没有原先指引或明确修订证据时，修订方向应为未知。
- 评级维持和目标价上调可以同时发生；不要合成一个模糊动作。
- 不使用后来股价涨跌判断抽取是否正确，也不使用它决定可靠性权重。

### 质量检查

先做训练期文章的类型和覆盖盘点，再确定小规模标注集。此前助手审阅过的样本可以复用为开发/复核材料，不能重新称作未见检查集。另留未用于修改规则的文章，由组员独立复核关键字段与逐字证据。

90% 可以是预先设定的候选门槛，不是质量保证。报告分事件、分股票的字段精确率、端到端对象与动作正确率、漏抽和覆盖率及样本数；不能用大量“不适用”字段或少数容易例子抬高正确率。若覆盖少到不能训练下游模型，记录数据限制，不自动扩展到所有事件类型。

先处理规则能明确识别的句式；歧义保留未知。已有 Qwen pilot 未通过语义质量检查，不能直接作为全量可靠抽取器。

## 5. 对 side chat 时效公式的补充

保留发布时间、可用时间、抓取延迟与首次披露证据。**文章发布时间不自动等于事件首次披露时间。** 对回顾文章无法确认首次披露时，使用明确标记的代理时间或输出未知，不根据模型常识补精确日期。任何代理年龄都不能让文章在实际可用之前进入窗口。

将建议式写为：

\[
w_{e,t}=q_e2^{-a_{e,t}/H},\qquad S_t=\sum_e w_{e,t},\qquad
z_t=\frac{\sum_e w_{e,t}f_e}{\lambda+S_t},\quad\lambda>0.
\]

第一版可固定 λ=1，保留不衰减对照，H 只在训练期比较少量候选。q 是按预先规定的证据规则得到的分值；未经独立校准，不能称为“事件正确的概率”。

### “＋1”的作用是可解释的收缩

当 S>0 时，z 等于普通加权平均乘以 S/(λ+S)。例如只有一条事件，f=1、q=1，年龄为四个半衰期，则 w=1/16：

- 普通加权平均：仍为 1。
- λ=1 的收缩聚合：1/17≈0.0588。

它保留了“总证据很弱”的信息，这是与 E04 `w = w / w.sum()` 的实质区别。若特征范数不超过 M，则 \(\|z_t\|\le M S_t/(\lambda+S_t)\)。**总权重趋近零时，特征才有趋近零的保证。**

### 它不保证解决重复旧闻，也不保证预测准确

如果有 100 条相同旧报道，每条权重仍为 1/16，则聚合结果变成 6.25/7.25≈0.862。许多弱证据仍会累积为较强输入；如果这些是转载，等于重复计权。

所以要明确聚合单位：初版可保留逐文章处理作为对照，并记录同事件重复率；通过对象/动作/数值检查的重复事实再作归并或事件权重封顶对照。只能用截止前已知记录，不能借未来转载确定过去的事件簇。这样补充的是证据计量约束，**不是宣称旧 E06 去重已带来收益**。

此外，特征缩小不自动意味着学习后的概率贡献同倍缩小：标准化和重新拟合的系数可能补偿尺度。保留“无事件为零”的语义，记录训练变换后的实际新闻贡献；正则强度及特征尺度须一致。联合 LR 即使新闻全零也未必与独立价格模型相同，因为训练出的价格系数与截距可以改变。

如果将来要求无可靠新闻时严格回退同一个价格模型，可以单独检验固定价格预测加受限新闻残差；当前方案不预先增加这一模型。

## 6. B0–B3 与 graph 的定位

在统一的一种更新协议下比较：

| 对照 | 输入 | 解释 |
|---|---|---|
| B0 | 价格 | 同更新方式的新闻增量参照 |
| B1 | 价格＋候选事件类别/数量 | 控制覆盖、类型、计数 |
| B2 | B1＋目标动作、正确配对的数值变化、未知标记 | 检验具体事实是否增加信息 |
| B3 | B2＋时效/可靠性聚合 | 检验整套时间处理是否增加信息 |

B1–B3 使用相同候选文章、抽取版本和接受规则；全部无新闻或失败窗口保留。B3 同时改变多个时间处理部分，其成绩只能支持整体组件。若它有收益，再用相同事件事实比较普通加权平均与收缩平均、固定 q 与证据 q，识别关键贡献。

Graph 可以忠实存储“机构—发布—事件—对象公司—数值变化—证据—时间”。第一步从这些关系读出小规模特征即可。若没有消息传递或关系学习，不称为已经实现 GNN。Ding 等将知识图谱中的实体/关系信息纳入事件向量学习，为这一方向提供方法参考，但不能证明对我们两股小时任务有效。[Ding 等，2016](https://aclanthology.org/C16-1201/)

更复杂图模型必须与使用同一事实、同一上下文范围的普通聚合对比；增加其他股票数据也须给非图对照同样的可用历史。当前抽取质量与事件数量尚未支持直接上完整图系统。

## 7. 推荐的范围与停止条件

1. 先完成更新策略对照，确认定期更新是否值得保留。
2. 完成小规模事件事实质量检查和覆盖盘点。
3. 通过后才运行 B0–B3；否则保留抽取失败原因，停止扩量。
4. 再考虑一个次选方法：浅层提升树或训练期样本外概率融合；不要同时追加所有未试模型。
5. 事件更准但方向没有收益，就报告“输入质量改善，预测增益未证实”。多个时段无一致收益时冻结范围，完成报告和 demo。

换成日频、收益回归或只预测高置信窗口，都是另一个目标/覆盖条件，应单列任务，不能将其分数直接说成原一小时全窗口预测的提升。

课堂主线可以是：**静态词语模型能否通过定期更新，以及有对象、有变化、有时间的事件事实，获得更稳定的预测？** 目前这是一套具体的下一轮设计，本轮无新增实验成绩。
