# 本轮案例笔记

这些是内容阅读与保存输出的诊断，不是独立盲审，也不是从案例比例估计总体错误原因。市场涨跌标签没有进入标注或抽取训练。原文/完整输出只保存在本地。

## 先看标注环节

- **N0198，AMZN财报后的券商目标价汇总：** 原文明确说多家机构上调，三家给到同一新值。一轮给出三份相同字段、一轮当作无事件。保留一个有证据的同值事实，不把重复输出当额外信息；当前schema不含机构关系，因此不声称恢复了完整实体图。
- **N0031/N0067：** 评级维持有直接证据，目标价数字却没有明确币种。保留评级、排除不受支持的目标价；不把整篇标成无事件。缺字段与没有事实应分开。
- **D0029/D0036/D0037：** 三月文章正文写的是一月或上一年十二月的评级动作。两轮都容易把标题/导语当成当前变化。因无法确认新的披露，保留不确定状态并排除监督；不能因为两轮同意就直接当真。
- **D0013/N0239：** 原文自身的价格数字可疑。抽取器忠实复制数字不证明市场事实正确。此类记录只支持“按提供文本抽取”的评价，不能当作已验证金融事件。

## 最终检查：逐项阅读两个adapter的全部匹配与误报事实

检查输出不参与checkpoint选择。助手重读普通版6条匹配、8条错配，以及辅助损失版1条匹配、1条错配的原文片段。以下仍是助手复核，不是独立人工验收。

普通版正确匹配：N0415的AMZN目标价1750→1800、Q0000的neutral维持、Q0004的buy→hold降级、Q0014的hold→sell降级、Q0020的203→200目标价下调、Q0033的hold维持。N0415同时漏掉评级维持；其事件与N0417重复，不能视为独立事件证据。辅助版仅匹配Q0037的neutral维持。

| 普通版错配案例 | 原文与错误 | 问题 |
|---|---|---|
| N0428、N0450 | 持仓文章内的旧评级列表被当作当前维持动作 | 当前与背景混淆 |
| Q0003 | 多机构平均共识Buy被当作一个机构的维持评级 | 共识与动作混淆 |
| Q0006 | 明确从strong buy降至buy，却输出维持Buy | 丢失动作与旧值 |
| Q0007、Q0009 | 新设159/175目标价、方向未知，却输出上调 | 新设不等于提高 |
| Q0034 | 当前主事件是Deutsche设152，模型抽出背景Wells Fargo的195并称上调 | 数字存在但属于另一个事件 |
| Q0037 | 重申neutral，却补出原文未明确提供的旧值neutral | 推断旧值违反抽取约定 |

辅助版修正了Q0037的旧值问题，但漏掉普通版的6条正确事实；它仍把Q0009的新设目标价标为上调。因此辅助监督没有改善总体结果。字面证据校验可以挡住部分凭空数字，却不能单独解决历史背景、关系对象或动作含义。

## Context与prompt排查边界

全部537条输入最长939个prompt token，预留512个输出token仍在2048预算内，没有截断。训练与实际MLX推理的前缀token逐条相同。因此本轮未发现长度截断或模板错位；这不证明候选段落已包含所有关键内容，也不证明简短无few-shot的prompt最优。冻结模型209条开发/检查输出中143条缺少evidence_ids，说明输出约定适配是实际问题；微调大幅改善格式，却没有同时解决语义可靠性。
