# reaction v1 案例说明

本轮案例只用于解释输入和下游失败模式，不把暴露期结果包装成泛化证据。

1. **同一文章两个目标：**pair unit 允许一篇文章分别产生 AAPL/AMZN 记录；下游按 target 过滤，不把两个公司的 reaction 混成一条标签。
2. **重复报道：**canonical group 保留最早可用记录，并统计 4,556 个被压掉的候选。反应聚合不把同一事件的转载当作独立新信息。
3. **文章级成功、窗口级失败：**120m/240m AR1 在 article-level outer gate 通过，但 W1 使 AMZN 从 W0 的 60.63% 降到 45.51%/45.96%。这区分了“能预测文章后的实现反应”和“能改善四小时方向窗口”。
4. **严格门控：**W3 只在至少两个 reaction article 可用时调整；AMZN W3 回到 55.50%，仍低于 W0，说明减少稀疏窗口误调不能单独解决市场状态和时间漂移。
5. **AR2 覆盖限制：**冻结向量只有私有已有文章向量，不能把覆盖有限的 AR2 结果写成全语料语义模型结果。
