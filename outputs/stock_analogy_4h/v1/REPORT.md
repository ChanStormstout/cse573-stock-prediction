# V1 — aborted input-quality run

Before prediction evaluation, fixed input cards showed broad lexical retrieval
confusing wage announcements with market-cap stories and product comparisons with
insider selling. Short source headers also replaced substantive evidence. The run
was stopped; original prompts, partial token scores and source snapshot are retained
privately. No v1 BA/Brier was computed or used to revise the design.

See [V2 amendment](../V2_REGISTRATION.md). This failed retrieval design is preserved,
not represented as a completed forecast comparison or a general failure of RAG.
