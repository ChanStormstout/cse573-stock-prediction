# 论文方法落实与性能改进分析

日期：2026-09-15。主日志继续维护在 [PROJECT_LOG.md](../PROJECT_LOG.md)。本轮完成了论文核对、扩展诊断与 E04 控制实验；没有运行最终测试。

## 1. 之前调研的论文，实际用上了什么？

核对了原始对话中的论文清单。此前核心是 Alostad & Davulcu 2017、StockNet 2018、FinBERT 2019、CausalStock 2024，以及历史前视偏差研究。不能把“读过”“借鉴一个设计”和“复现论文”混为一谈。

| 论文 | E03 结束前实际状态 | 本轮补充与仍未实施部分 |
|---|---|---|
| [Alostad & Davulcu 2017](https://journals.sagepub.com/doi/pdf/10.3233/WEB-170349?download=true) | 使用新闻小时聚合、LR 与词特征思路；没有二值词袋/Chi-square/L1 组合 | E04 补二值 unigram + 训练期卡方 top500 + L1；仍只用标题、未词干化，时间验证也不同，属于方法改编。目标公司正文句提取、Twitter 消息量突增与完整系统未复现。 |
| [StockNet 2018](https://aclanthology.org/P18-1183.pdf) | 借鉴文本与价格联合输入；等权聚合 | 补固定时间衰减是本项目的简化对照，不是 StockNet 注意力复现；变分生成模型、递归潜变量与时间辅助目标未实现。 |
| [FinBERT 2019](https://arxiv.org/abs/1908.10063) | 实际加载官方金融情绪模型，冻结推理 | E04 进一步提取最后隐层 768 维均值表示，训练期 PCA16 后做分类。无微调，也不是完整重做作者的情绪分类训练实验。 |
| [CausalStock 2024](https://proceedings.neurips.cc/paper_files/paper/2024/file/54d689d58fe54c92aee2d732fc49fca8-Paper-Conference.pdf) | 仅借鉴新闻降噪动机 | 未实现 LLM 五维新闻评分、时滞因果发现或功能因果模型；简单新鲜度过滤不能称为 CausalStock。 |
| [Glasserman & Lin：前视偏差](https://arxiv.org/abs/2309.17322) | 记录现代模型用于历史数据的限制 | 它是评估风险参考，不是预测组件。固定模型版本并不能证明其预训练语料与历史测试完全无重合。 |

另外本轮补查了 [Ding 等，IJCAI 2015](https://www.ijcai.org/Proceedings/15/Papers/329.pdf) 的事件表示思路：它显式处理事件参与者与关系。这是新补充参考，不能说之前已经实现了其神经张量网络或 CNN。

**对前面实施顺序的反思：** 先跑冻结情绪是合理的低成本对照，但不能因此说语义方案已经做完。指定论文早已报告情绪附加收益不显著，后续应更快检验关键词稀疏选择、目标公司内容与事件，而非把情绪当默认有效的改进。

## 2. 覆盖更多案例，如何避免只增加数量？

现在包括：全体 504 个窗口统计、96 个分层案例卡、24 例助手逐例审阅，其中 8 个案例进一步核对正文摘录（7 条不同记录）。程序卡和实际阅读明确区分。覆盖公司、月份、四种模型正确/错误组合、新闻数量、滞后程度、时段、实际涨跌幅以及无新闻窗口。

[扩展案例分析与具体证据](../stock_diagnostics/QUALITATIVE_REVIEW.md)。

全量结果中只有 50 个窗口因模型变化而翻转方向：24 个改善、26 个恶化。89/504 个目标绝对收益小于 0.1%，其余窗口也没有强表现，所以不能简单把低分归因于微小涨跌。

## 3. E04 的实验设计

- 保持训练/验证样本、标签、预测时刻与目标不变，测试数据不进入实验。
- 新增参数选择协议：只在训练期做三次向前验证（之前月份训练，分别在 6、7、8 月验证），按平均 BA 选 C，平手看 Brier。C 固定 0.01、0.1、1。最终在 1–8 月重训，再查看 9–10 月结果。
- 因协议变化，E04 同时重跑价格和情绪参照；不把 E03 验证集择优分数与 E04 训练期择优分数混成一张公平比较表。
- 先登记 9 组特征实验。检查后发现论文式组合同时改变了 L1 正则化，追加第 10 组价格 L1 对照；追加原因与时点保存在 `protocol_l1_control.json`，没有隐瞒为预注册。
- 每个特征候选和变换都在训练折内拟合，包括词表、卡方、PCA 和缩放。验证集已经被我们多轮分析，仍是开发数据，不是无偏最终成绩。

### 三个具体改动

**价格新鲜度：** E02 的历史小时信息距截止点中位数为 55 分钟。目标前完整小时尚未结束，但其中已结束的 5 分钟线可以用；新增最近 5/15/55 分钟收益和连续性标记后，最新价格距截止点中位数变为 0 分钟。0 表示数据区间恰好结束于截止点，仍假设此时可获得，真实行情分发延迟未知。

**新闻新鲜度：** 将原窗口中抓取比发布晚超过 4 小时的记录排除，保留变成无新闻的样本并重算数量。AMZN 验证新闻覆盖率由 66.7% 降到 39.7%；AAPL 由 99.2% 降到 96.8%。减少噪声与损失覆盖是共同发生的，不能只看清洗后剩下的有新闻样本。

**文本表示：** 分别测试固定 1 小时半衰期、冻结隐层语义向量，以及论文式稀疏词特征。语义向量在每个训练折内降至 16 维，避免将约千个样本直接拟合高维表示。

## 4. 实际结果：验证集平衡准确率

| 方法 | AAPL | AMZN |
|---|---:|---:|
| 价格 L2 | 51.20% | 48.87% |
| 价格 L1 对照（追加） | 51.90% | 49.26% |
| 价格 + 最新 5 分钟信息 | 51.21% | 50.86% |
| 价格 + 新闻数量 | 49.17% | 49.26% |
| 价格 + 标题情绪 | 49.99% | 50.84% |
| 价格 + 过滤滞后后的情绪 | 48.77% | 50.87% |
| 价格 + 时间加权情绪 | 48.74% | 49.26% |
| 价格 + 隐层语义向量 | 50.13% | 47.16% |
| 二值词袋 + Chi-square + L1 | 49.75% | 47.64% |
| 价格 + 二值词袋 + Chi-square + L1 | 52.72% | 50.03% |

### 怎么解读

- AAPL 的论文式组合为 52.72%，9/10 月分别约 53.24% / 52.67%，比同轮价格 L2 51.20%、价格 L1 51.90%略好。这只是候选信号，不能宣称稳定提升；按日重采样差值区间仍跨 0。
- AAPL 稀疏组合只保留 9 个非零权重，其中 3 个文本词为 `bought`、`marketwatch`、`sold`；AMZN 只保留一个文本词 `apple`。模型可能依赖来源、格式或共同提及，不是已证明学会事件含义。
- 新价格信息虽更新了输入，在 AAPL 基本没变；AMZN 有约 2 个百分点的开发增幅，仍接近 50%，概率误差未稳定改善。输入更新更及时不等于新增稳定信号。
- 语义向量、时间加权、滞后过滤均没有形成跨股票、跨月份的一致优势。尤其不能看到某个切片好就继续挑阈值。
- 多个方法在训练期向前验证中有 54–58% 左右 BA，移到 9–10 月下降；这提示泛化/时间稳定性是主要未解决问题，但不能仅凭分数确认具体市场机制变化。

## 5. 最值得验证的下一条路径

### 优先级 1：目标公司相关内容（E05，尚未执行）

案例 AMZN-104：标题是多公司升级/降级汇总，整体情绪明显负面；正文的 Amazon 段落实际为维持 Buy 且上调目标价。AAPL-185 的正面情绪则主要来自竞争对手微软。这里有具体输入证据，支持修正表示对象。

实现：从本地正文中找公司名称/代码所在句或段，保留必要上下文，显式记录对象与引用；找不到则回退标题并标记。先比较“原标题”和“目标段落”的冻结 FinBERT 特征，保持原文章集合与样本不变。规则仅在训练新闻上制定，检查公司消歧和截断。不要同时改窗口、样本筛选和下游模型。

### 优先级 2：近似重复与事件内容（E06，尚未执行）

AAPL-094 同一指控事件多次出现；AAPL-200 同一旧涨价标题有不同来源后缀。仅按正文或标题精确哈希去重不够。按当时已出现的文章做近似归并，先用训练数据核对阈值，每个事件聚合一次，同时单独保留来源数量。若提取事件属性，应有原文支持的主体、行为、对象、发生/预告/回顾，以及可获得的实际与预期差异。不能捏造市场预期。

### 优先级 3：更稳定的监督学习

继续用训练期向前验证，关注各月效果方向是否一致，保持模型容量小。两只股票共享模型加股票标记可以作为有限候选，但两只股票同一天并非独立样本；尚未做该实验。当前没有证据支持优先投入完整 StockNet、CausalStock 或大模型微调。

### 什么才算有效提高 performance？

需要同时满足：相同任务与覆盖率下超过合适基线；跨月份/股票尽量一致；概率误差不过度恶化；改动的增益由对照支持；方法冻结后在最终留出数据中仍成立。单次 1–2 个百分点、只剩少数容易样本、或参数搜索更多都不够。无法预先保证下一轮提高多少。

## 复现与证据

- 协议：`protocol.json` 与追加控制 `protocol_l1_control.json`。
- 执行：从任务根目录依次运行 `work/stock-data/finbert-env/bin/python outputs/stock_improvement/run.py`、`run_l1_control.py`、`check.py`（后两者也在同一目录）。
- 依赖 E02/E03 产物与本地原始数据；不是从空目录自动下载的独立发行包。
- `results/results.json`：完整模型指标和月份结果。
- `results/{AAPL,AMZN}/training_cv_grid.csv`：所有训练折与 C 的记录。
- `results/{股票}/feature_manifest.csv`：每个样本的新闻特征、最新价格时点及标签。
- `results/{股票}/development_embeddings.npy`：与清单行顺序对应的 768 维聚合向量。
- `results/{股票}/paper_nonzero_weights.csv`：稀疏模型真正使用的词与价格特征。
- `results/descriptive_intervals.json`：按交易日重采样 1,000 次的开发差值区间，不纠正多模型选择或跨日相关性。
- `check_result.txt`：标签与行未变、无测试评估、时间边界、缓存概率复现、PCA/缩放与参数选择范围检查。

库给出了旧版 `penalty` 参数弃用提醒；检查当前实现确认原 E04 模型实际使用 L1，非零权重也已保存。后续代码迁移时可改为对应 `l1_ratio`，本轮不将提醒误判为训练失败。
